# VEX V5 ClawBot AugDrive

### A VEX V5 ClawBot program that augments manual driving capabilities and features.


#### Created by Davis Hawkins
#### Current Release: v1.0
#### Released: 9/02/2026

## Controlling The VEX V5 ClawBot
The AugDrive program makes it possible to switch the control scheme for driving the robot. On the V5 brain screen, a menu is displayed with control scheme options. The active selection is highlighted in green. There are 3 control schemes:
 - One Stick (Default scheme)
 - Two Stick
 - Tank

To change the current control scheme, press the button on the controller with the corresponding letter on the V5 brain screen.

## Block Code
Block code was used for development to make modifying code simple, easy, and straightforward.

## Physical Wiring
In order for the AugDrive program to function properly, confirm that each cable is plugged into the correct port on the V5 brain:
- Left Motor -> Port 1
- Right Motor -> Port 10
- Arm -> Port 8
- Claw -> Port 3
